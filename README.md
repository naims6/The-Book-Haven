# 📚 The Book Haven

**The Book Haven** is a modern full-stack web application built with **React** and **Tailwind CSS**, designed for book lovers.  
Users can explore, share, and manage their favorite books — with authentication, CRUD features, comments, and dark/light mode.

Built with **React**, **Tailwind CSS**, **Firebase Auth**, **Node.js**, **Express**, and **MongoDB**.

🌙 Dark/Light Mode • 💬 Real-time Comments • ⭐ CRUD + Ratings

## 🧩 Features

### 👤 Authentication

- Secure **Login** and **Signup** system
- Firebase used for user authentication
- Only logged-in users can add, edit, delete, or comment on books

### 📖 Book Management (CRUD)

- **Add Book** – title, author, genre, rating, summary, cover image
- **Update Book** – edit your own books
- **Delete Book** – remove only your own books
- **View Books** – browse books added by the community

### 💬 Comment System

- Logged-in users can comment on any book
- Real-time timestamp on comments

### 🎨 UI & UX

- Clean, responsive design using **Tailwind CSS**
- Modern layout built with **React Components**
- **Dark Mode** / **Light Mode** toggle with persistent theme storage

### ⚙️ Sorting & Filtering

- Sort books by rating, creation date
- Search and filter options for better user experience
